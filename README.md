One line, 119 characters: the funniest voicemail greeting a cat would record. Miso confesses to the vase — unrepentant — from inside the box it came in. A cat-specific joke (knocking things off shelves, hiding in boxes) with a clear voice of its own, built to land spoken aloud in the few seconds a caller waits.

> "Hi, it's Miso. About the vase, I did it and I'd do it again. Leave a message after the beep. I'm in the box it came in."

## Run it

```sh
python3 main.py
```

This writes the greeting to `/output/entry.txt`.
